#  SCTEC SENAI - 💻 Protótipo de Portfólio 

Este projeto é um protótipo de portfólio pessoal desenvolvido como atividade prática durante o curso livre de Introdução a programacao front-end e back-end na **SCTEC/SENAI**. 
O objetivo principal foi aplicar conceitos de desenvolvimento web para criar uma vitrine virtual dos meus projetos e habilidades
(Esse projeto de portfólio ainda não está 100%, pois não tiver tempo para trabalhar nele, mas pretendo transforma-lo em meu **portiflio oficial**.)

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:
* **HTML5:** Estruturação semântica do conteúdo da página de acordo com o ensinando durante o curso.
* **CSS3:** Estilização básica dos elementos presentes na página
